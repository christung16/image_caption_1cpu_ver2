🧠 How Does This Work?

Step 1: You provide an image (URL or file upload)
Step 2: The image is sent to our Python Flask server
Step 3: The BLIP AI model analyzes the image
Step 4: The model generates a descriptive caption
Step 5: The caption is displayed on your screen

💻 Technologies Used

  • Backend: Python 3.8+ with Flask
  • AI Model: BLIP-base (Salesforce)
  • Libraries: PyTorch, Transformers, PIL
  • Frontend: HTML5, CSS3, JavaScript
